# 2026-03-19

## PlateColor 插件修复 - 宠物血条宽度问题

### 问题
选中敌方宠物后，宠物血条宽度非常宽（拉到最小也是很长），因为选中时 `nameplateSelectedScale`（默认1.2）会放大整个姓名板框体，而宽度公式 `-hpWidht+50` 中的偏移量不够大。

### 尝试过的方案（失败）
- `SetSize` + 居中锚点：导致布局循环，血条一直闪烁
- `SetScale` 反向缩放：同样触发 `UpdateAnchors` 导致闪烁

### 最终方案
保持原来的两端锚定方式（稳定不闪），扩大宠物宽度滑块范围到 **-20 ~ 50**，允许负值让血条更窄。
- 值越小，`-hpWidht+50` 偏移越大，血条越窄
- 负值时（如 -20），偏移=70，血条会非常窄
- 选中时默认值从20降低到10

### 修改的文件
1. **Anchors.lua** - 恢复原来的锚定方式，去掉 SetSize/SetScale
2. **DB/DefaultDB.lua** - petSelectedHpWidth 默认改为10，去掉 petSelectedScale
3. **Options/Tab8.lua** - 宽度滑块范围改为 -20~50，去掉缩放滑块
4. **Locales/DefaultzhCN.lua** - 更新提示文本，去掉缩放相关条目

### 关键公式
宽度公式：`-hpWidht + 50`，值越大血条越宽，值越小（负值）越窄
- 基础玩家默认25 → 偏移25
- 宠物未选中默认15 → 偏移35（更窄）
- 宠物选中默认10 → 偏移40（更窄）
- 滑块最小-20 → 偏移70（非常窄）
